## Criterios de Calidad Generales

Todos los entregables deben cumplir:

### Para Código:
- [ ] Sigue convenciones de estilo del proyecto
- [ ] Tiene tests unitarios con cobertura > 80%
- [ ] Documentación técnica actualizada
- [ ] Sin vulnerabilidades de seguridad conocidas
- [ ] Performance dentro de parámetros aceptables

### Para Documentación:
- [ ] Información precisa y actualizada
- [ ] Formato consistente con estándares del proyecto
- [ ] Fácil de entender para la audiencia objetivo
- [ ] Incluye ejemplos cuando es necesario
- [ ] Revisada por al menos una persona adicional

### Para Configuraciones:
- [ ] Testeadas en ambiente de desarrollo
- [ ] Documentadas con comentarios explicativos
- [ ] Versionadas en control de código
- [ ] Backup de configuraciones anteriores realizado

## Proceso de Entrega

1. **Desarrollo:** Crear el entregable según especificaciones
2. **Auto-revisión:** Validar criterios de aceptación
3. **Peer review:** Revisión por par/colega
4. **Testing:** Validación funcional y de calidad
5. **Documentación:** Actualizar documentación relacionada
6. **Entrega:** Marcar como completado y notificar
7. **Validación final:** Confirmación de stakeholder
